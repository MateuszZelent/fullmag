# Swept Hex Mesh

The public schema represents a hexahedral sweep with quadrilateral source faces. It is incompatible
with the prism-to-pyramid-to-tetrahedron transition used by the strict layered-prism route.

At the reviewed Control Room capability boundary, `swept_hex` is visible but disabled as
unsupported. Documentation of the schema is not a production execution claim. A future qualified
route must prove conforming connection to neighbouring regions and native operator support for every
realized hex family and order.
