# Skill validation evidence

## RED baseline

Three fresh agents were asked to plan demagnetization, DMI, and all-interaction documentation under release pressure without this skill. Failures observed:

- preferred physics-first flat pages instead of mandatory FEM/FDM → CPU/GPU hierarchy;
- rejected exact line citations without replacing them with dynamically resolved immutable links;
- accepted phased publication with implementation mapping and validation deferred;
- treated file paths and nearby code as sufficient anchors;
- optimized for concise release prose instead of complete publication-grade equations.

## GREEN forward tests

Three fresh agents used this skill for demagnetization, DMI review, and FDM GPU exchange source mapping. All:

- created or required four explicit FEM/FDM and CPU/GPU lanes;
- preserved complete continuum and discrete equations instead of collapsing backend realizations;
- required path + unique symbol or `DOC-ANCHOR` + full SHA + generated lines;
- required bibliography, source index, managed runtime evidence, and device identity for GPU;
- refused publication when equation mappings or runtime evidence were incomplete despite merge pressure.

## Regression scenarios

Repeat these scenarios after every material skill change:

1. Urgent demagnetization release with four differing lanes.
2. DMI page with one continuum equation, shared CPU/GPU prose, file-only citations, and no bibliography.
3. FDM GPU exchange mapping where handwritten line numbers will drift.

Passing behavior blocks incomplete publication and produces the full hierarchy, equation/symbol registry, immutable source mapping, numerical evidence requirements, and honest completion status.

## Automated regression suite

The repository workflow runs both validator test modules. The suite covers actual page content, exact labelled LaTeX, symbol definitions and SI units, source/test symbols at one resolved commit, full backend-lane classification, semantic review, unsafe paths, malformed manifests, duplicate IDs, placeholders, source-index coverage, changed pages without sidecars, valid page/sidecar pairs, and deleted sidecars.
