# Oersted field interaction

- Status: implemented with lane-specific qualification limits
- Owner: Fullmag physics and native backend documentation
- Canonical public owners:
  - `public_docs/site/physics/interactions/oersted-field/index.md`
  - `public_docs/site/python-api/interactions/oersted-field.md`

## Scope

The Oersted interaction is a prescribed magnetic effective field generated by a current source.
The current implementation has two public authoring forms:

1. `OerstedCylinder`, which describes an analytic infinite straight cylindrical conductor; and
2. `OerstedField(model="from_current_solution", source=...)`, which binds the field to a named
   `CurrentTransport` module and is lowered either to the exact cylinder realization or to a
   planner-generated midpoint Biot–Savart field.

These are field drives, not a standalone deterministic energy term in the current public contract.
The implementation adds $\mathbf H_{\mathrm{oe}}$ to $\mathbf H_{\mathrm{eff}}$ and does not publish
`E_oe` as an energy accumulator. The planner therefore rejects conservative relaxation workflows
that require field-energy parity for Oersted terms.

## Governing model

Let $\hat{\mathbf a}$ be the normalized current axis and let $\mathbf c$ be a point on the
axis. Define

```{math}
:label: eq-oersted-perpendicular-vector
\mathbf r_\perp(\mathbf x)
=\mathbf x-\mathbf c-
\bigl[(\mathbf x-\mathbf c)\cdot\hat{\mathbf a}\bigr]\hat{\mathbf a},
\qquad r=\|\mathbf r_\perp\|.
```

For a cylinder of radius $R$ carrying current $I(t)$, Ampere's law gives the azimuthal
magnitude

```{math}
:label: eq-oersted-cylinder-magnitude
H_\varphi(r,t)=
\begin{cases}
\dfrac{I(t)\,r}{2\pi R^2},&0<r<R,\\[6pt]
\dfrac{I(t)}{2\pi r},&r\ge R,\\[6pt]
0,&r=0.
\end{cases}
```

The vector field is

```{math}
:label: eq-oersted-cylinder-vector
\mathbf H_{\mathrm{oe}}(\mathbf x,t)
=H_\varphi(r,t)\,
\frac{\hat{\mathbf a}\times\mathbf r_\perp}{r}
\qquad (r>0),
\qquad
\mathbf H_{\mathrm{oe}}(r=0,t)=\mathbf 0.
```

The current envelope is separated from the unit-current spatial basis:

```{math}
:label: eq-oersted-current-envelope
I(t)=I_0g(t).
```

The currently executable analytic envelopes are

```{math}
:label: eq-oersted-time-envelopes
g(t)=
\begin{cases}
1,&\text{Constant},\\
\sin(2\pi f t+\phi)+o,&\text{Sinusoidal},\\
\mathbf 1_{[t_{\mathrm{on}},t_{\mathrm{off}})}(t),&\text{Pulse}.
\end{cases}
```

The half-open pulse interval is intentional: the source is active at $t_{\mathrm{on}}$ and
inactive at $t_{\mathrm{off}}$. `PiecewiseLinear` and `SincPulse` can be authored as time
dependence objects, but the current Oersted planner rejects them for this interaction; they are
not silently approximated by a supported envelope.

For a prescribed current density $\mathbf J$ in a source domain $\Omega_J$, the general field is

```{math}
:label: eq-oersted-biot-savart
\mathbf H_{\mathrm{oe}}(\mathbf x)
=\frac{1}{4\pi}\int_{\Omega_J}
\frac{\mathbf J(\mathbf x')\times(\mathbf x-\mathbf x')}
{\|\mathbf x-\mathbf x'\|^3}\,\mathrm dV'.
```

The native FEM and public FDM generalized paths use the regularized midpoint approximation

```{math}
:label: eq-oersted-midpoint
\mathbf H_{\mathrm{oe}}(\mathbf x_i)\approx
\frac{1}{4\pi}\sum_{s\in\mathcal S}
\frac{\mathbf J_s\times(\mathbf x_i-\mathbf x_s)}
{\bigl(\|\mathbf x_i-\mathbf x_s\|^2+a_s^2\bigr)^{3/2}}V_s,
\qquad
a_s=\left(\frac{3V_s}{4\pi}\right)^{1/3}.
```

$\mathbf x_s$ is a source-cell or source-tetrahedron midpoint/centroid, $V_s$ is its volume,
and $a_s$ is an equivalent-sphere regularization radius. This is an explicit approximation to
the Biot–Savart integral, not a current-contact or Ohmic-Poisson solve. For a uniform cylindrical
source the planner uses the analytic reduction instead:

```{math}
:label: eq-oersted-current-reduction
I=(\mathbf J_0\cdot\hat{\mathbf a})\pi R^2,
\qquad
\mathbf J_0\parallel\hat{\mathbf a}.
```

## Assumptions, validity, and explicit limits

- The analytic cylinder is an infinite, straight conductor. Finite-length end effects, current
  crowding, contacts, and return paths are not included.
- `axis` is normalized by the native FEM cylinder path and must be finite and non-zero. FDM CUDA
  additionally requires exactly $+\hat{\mathbf z}$ until an arbitrary-axis geometry kernel is
  qualified.
- `current` may be positive or negative; its sign reverses the field chirality. `radius` must be
  strictly positive.
- `from_current_solution` currently requires `CurrentTransport(model="prescribed_density")` and
  a named `solve_region`. The source current density must be axis-parallel for the exact cylinder
  reduction.
- A non-cylindrical prescribed source uses the midpoint approximation and is subject to the
  public FDM active-source-cell limit and FEM tet4/source-selector restrictions.
- `CurrentTransport(model="ohmic_poisson")` remains semantic-only for this interaction.
- The Oersted module does not multiply by $\gamma$, $\alpha$, or $\mu_0$; LLG consumes the resulting
  field in A/m. It also does not materialize an exchange-like or Zeeman-like scalar energy.
- Conservative relaxation rejects Oersted terms until the selected lane has the required identical
  field-energy parity. A dynamic time evolution and a conservative minimization are therefore not
  interchangeable requests.

## Backend and qualification matrix

| Solver | CPU | GPU |
|---|---|---|
| FDM | Double-precision reference path supports analytic cylinders and planner-generated midpoint fields for the current single-body source path. CPU accepts Constant, Sinusoidal, and Pulse envelopes; generalized fields do not publish a separate energy scalar. | Native CUDA consumes precomputed analytic-cylinder fields in FP64/FP32 and generalized planner fields. CUDA cylinder currently requires $+z$ and Constant envelope; FP32/FP64 runtime qualification is separate. |
| FEM | Native MFEM CPU samples an analytic unit-current cylinder at nodes or consumes final explicit nodal $H_{\mathrm{oe}}$. CPU materializes accepted-time envelope values before adding to $H_{\mathrm{eff}}$. | Native CUDA keeps cylinder basis and realized $H_{\mathrm{oe}}$ device-resident, evaluates supported envelope values at each RK stage, and accumulates the field on device. Explicit generalized fields are final H values and are not rescaled. |

Implementation availability in this matrix is not a claim of current-revision numerical parity.
The qualification state must include the requested/resolved lane, precision, device identity,
field decomposition, and accepted-time snapshot evidence.

(problem-statement)=
## 1. Physical problem

The interaction computes the magnetic field generated by a prescribed current source and adds it
to the effective field used by the LLG right-hand side. It does not solve a coupled electromagnetic
problem in the current public contract. The analytic cylinder and generalized current-source
paths are two numerical realizations of the same field-generation problem, not two different
physical interactions.

The validity conditions are the cylinder geometry, axis, envelope, prescribed-density, source
selection, regularization, and energy limitations listed above. A planner acceptance is not proof
that the approximation is accurate for a finite conductor or that a GPU lane is qualified.

(problem-ir)=
## 6. ProblemIR and planner resolution

`OerstedCylinder` lowers to an `oersted_cylinder` term with current, radius, centre, axis, and an
optional envelope. `OerstedField` lowers to an `oersted_field` term referencing a named current
transport. The planner resolves the latter to `infinite_cylinder` or `biot_savart_midpoint` and
records the resolved backend details separately from requested intent.

(round-trip-and-failure-semantics)=
## 7. Round-trip and failure semantics

Requested intent preserves the authored term, current source, geometry binding, envelope, and SI
values. Resolved execution records solver, device, precision, field realization, source element
selection, regularization, and qualification evidence. Validation errors include non-positive
radius, invalid vectors, unknown model/source, missing `solve_region`, non-cylindrical exact-source
requests, non-axis-parallel current, unsupported envelope, and invalid output/relaxation requests.
Unsupported combinations fail closed; they do not silently fall back to a different field model.

(discrete-realization)=
## 8. Discrete realization by solver and device

### FDM / CPU

The CPU reference adds the analytic cylinder field through `oersted_field_add_into` and can also
consume a planner-generated per-cell midpoint field. Cell-centre positions and the regularized
source-cell sum are distinct from the analytic infinite-cylinder formula.

### FDM / GPU

The CUDA context precomputes a unit-current cylinder field on the host, uploads it in the selected
precision, and scales it in the effective-field path. Generalized planner fields are uploaded as
resolved per-cell values. The CUDA planner currently gates axis and envelope combinations before
runtime execution.

### FEM / CPU

The native CPU path normalizes the cylinder axis, samples a unit-current nodal basis, materializes
the accepted-time envelope, or imports an already-final explicit nodal field. The aggregate
dispatcher adds the realized field exactly once to $\mathbf H_{\mathrm{eff}}$.

### FEM / GPU

The native GPU path uploads the cylinder basis and explicit field buffers, evaluates supported
time envelopes at RK evaluation times, and accumulates the realized field on device. The basis is
not exposed as `H_oe`; public copies and snapshots use the realized accepted-time field.

(limitations)=
## 11. Limitations and deferred work

- No `ohmic_poisson` current solve, finite-contact solve, return-path solve, or conductor end effect.
- No hybrid current-to-Oersted coupling.
- General midpoint Biot–Savart is regularized and approximate; it is not interchangeable with the
  exact infinite-cylinder field.
- FDM generalized lowering is currently single-body and bounded by active source-cell count.
- FDM CUDA has stricter axis/envelope gates than CPU and FEM.
- No standalone Oersted energy scalar or conservative Oersted minimization qualification.
- `PiecewiseLinear` and `SincPulse` are not executable Oersted-cylinder envelopes on current lanes.
