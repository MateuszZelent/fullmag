### 3.1 Nowy klient API (`src/api/client/`)

**34 pliki TypeScript** — wszystkie zaimplementowane.

#### `LiveApiClient` — architektura

```
LiveApiClient (singleton)
├── StatusModule       →  GET /v1/live/current/status
├── DomainModule       →  GET /v1/live/current/domain/{meta,topology,coordinates}
├── FieldsModule       →  GET /v1/live/current/fields/...
├── ScalarsModule      →  GET /v1/live/current/scalars
├── DisplayModule      →  PUT /v1/live/current/display
├── CommandsModule     →  POST /v1/live/current/commands

├── EigenModule        →  GET /v1/live/current/eigen/...

├── GpuModule          →  GET /v1/live/current/gpu/telemetry
└── SystemModule       →  GET /v1/health, GET /v1/capabilities
```

#### Interceptor pipeline

```
Każdy request:
  1. requestId    →  dodaje header x-request-id: fm-{ts36}-{rnd6}
  2. retry        →  retry na 5xx (max 3), exponential backoff (200ms×2^n)
  3. versionCheck →  waliduje x-api-contract-version: "1.0.0"
  4. diagnostics  →  ring buffer 200 wpisów, czas, status, rozmiar
```

#### ResourceCache

- LRU eviction, domyślnie 100MB
- Walidacja po `revision` (pole `field_revision`)
- Invalidacja po `domain_generation_id`
- Klucze statyczne: `ResourceCache.domainKey()`, `ResourceCache.fieldKey()`
